DOKUMEN INTEGRASI SISTEM

Layanan Omnichannel
Bithinks x TikTok Shop API

Bithinks Omnichannel adalah platform System Integrator & Enterprise Resource Planning (ERP) multi-channel yang dikembangkan untuk menghubungkan sistem inventori retail, manajemen pesanan, dan POS fisik merchant secara mulus dengan e-commerce, khususnya melalui integrasi TikTok Shop API.

Sinkronisasi Dua Arah

Mengintegrasikan persediaan produk, pesanan, dan katalog harga merchant secara real-time ke seluruh channel e-commerce dari satu dasbor terpusat.

Manajemen TikTok Shop

Memungkinkan merchant memproses fulfillment pesanan TikTok Shop langsung dari Bithinks ERP, termasuk cetak label pengiriman otomatis.

Keamanan & Kepatuhan

Didesain menggunakan protokol otentikasi resmi OAuth 2.0 TikTok Shop API dengan standardisasi enkripsi data untuk menjaga privasi merchant.

KEMAMPUAN PLATFORM

Fitur Omnichannel yang Dibangun

01 Sinkronisasi Stok & Inventori Real-Time

BitOmni (layanan inti omnichannel Bithinks) bertindak sebagai pusat kebenaran persediaan barang. Saat barang terjual di etalase TikTok Shop Anda, sistem Bithinks otomatis mengurangi stok di gudang fisik utama dan memutakhirkan stok di e-commerce lainnya.

  • Sinkronisasi instan dalam hitungan detik setelah penjualan terjadi.
  • Mencegah double-selling & pembatalan pesanan yang merugikan performa toko.
  • Mendukung set batas stok minimum (safety stock) per cabang / etalase toko.

02 Manajemen Pesanan & Pemrosesan Otomatis

Bithinks mengumpulkan semua pesanan baru dari TikTok Shop secara real-time. Merchant dapat langsung memproses pesanan tersebut di dalam dashboard Bithinks tanpa harus login bolak-balik ke Seller Center TikTok Shop.

  • Tarik data pesanan otomatis menggunakan API Webhook.
  • Proses pesanan massal (Accept Order, Request Pickup/Drop-off) sekali klik.
  • Pembuatan dan pencetakan Label Pengiriman (Shipping Label/Airway Bill) resmi dari ekspedisi terintegrasi TikTok Shop.

03 Sinkronisasi Produk & Manajemen Katalog

Mengelola data produk di multi-channel menjadi sangat mudah. Merchant cukup mengunggah satu "Master Product" di platform Bithinks, lalu menyebarkannya ke TikTok Shop beserta gambar, deskripsi, harga khusus, dan variasi warna/ukuran.

  • Pembuatan produk dan variasi secara massal di TikTok Shop.
  • Update harga dinamis (misalnya ketika ada event promo) dari satu input pusat.
  • Manajemen gambar produk dan media teroptimasi sesuai standar ukuran TikTok Shop.

PERSYARATAN TEKNIS

Justifikasi Akses Scope TikTok Shop API

Bithinks berkomitmen untuk hanya menggunakan hak akses API yang krusial guna menjamin integritas data operasional bisnis merchant kami. Berikut adalah rincian scope API yang kami ajukan:

Scope API Modul Terkait Tujuan & Justifikasi Penggunaan
product.mgt Manajemen Katalog Digunakan untuk mengambil info produk terdaftar di TikTok Shop, mencocokkannya dengan SKU master Bithinks, serta memperbarui deskripsi atau gambar dari dasbor terpadu Bithinks.
inventory.mgt Manajemen Stok Sangat penting untuk memperbarui kuantitas persediaan stok (stock level) secara real-time begitu ada penjualan di toko offline (POS) atau e-commerce lain, sehingga mencegah over-selling.
order.mgt Proses Pesanan Digunakan untuk menarik data pesanan baru dari TikTok Shop secara berkala, menampilkan status pembayaran, dan memetakan order tersebut ke dalam antrean fulfillment Bithinks.
fulfillment.mgt Logistik & Kurir Digunakan untuk memesan kurir penjemputan paket (request pickup), mengambil data tracking AWB, dan mencetak label pengiriman resmi untuk memudahkan operasional warehouse merchant.
reverse_logistics.mgt Layanan Pelanggan Digunakan untuk mendeteksi pembatalan pesanan atau permintaan retur dari pembeli di TikTok Shop sehingga stok inventori dapat dikembalikan secara otomatis ke gudang merchant.

Keamanan & Perlindungan Data

Bithinks mengimplementasikan perlindungan data tingkat lanjut untuk mematuhi regulasi privasi pelanggan dan Developer Policy yang ditetapkan oleh TikTok Shop.

OAuth 2.0 Resmi

Merchant mengotorisasi tokonya menggunakan link login resmi TikTok. Bithinks tidak pernah menyimpan password seller.

Enkripsi Token

Access Token dan Refresh Token TikTok Shop API disimpan di database menggunakan enkripsi standar AES-256 yang aman.

Pembatasan Akses (RLS)

Menggunakan PostgreSQL Row Level Security (RLS) untuk menjamin isolasi data antar tenant (tidak ada kebocoran data toko).

Audit Log Lengkap

Setiap call API dan pembaruan stok dicatat dalam sistem log audit untuk analisis pemecahan masalah (troubleshooting) secara transparan.
